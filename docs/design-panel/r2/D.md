# Seat D, Round 2

## Kill shots
- **A1 (serious, c6):** a two-room stage at 500 px is really 30–43 KB per send (lit rooms 13–19.5 KB, sprites 1.7 KB, ≈2 KB markup); a busy 13 s turn changes the scene every second → 30–43 KB/s; one room (17–23 KB/s) only just survives.
- **A2 (tolerable, c4):** an early walk on an Edit chunk runs into a permission prompt; the provisional entry drops at 3 s and Kit walks back, then walks again at approval — the office acted out an edit that was not happening.
- **B1 (serious, c4):** SMIL re-sent on every state change restarts all motion; in a busy turn the office stutters once a second and no flourish finishes.
- **B2 (serious, c7):** "media query turns off SMIL" is false.
- **B3 (fatal, c1/c8):** cloud falls back to unverified toasts and never uses the verified channel (the command reply); terminals lose the office (no Raster; Svg via Image is false).
- **C1 (serious, c6):** 2/s at real sizes = 34–46 KB/s.
- **C2 (serious, c4/c7):** SMIL walks restart on every re-send: Pax "arrives" three times for one finished call; the Client fallback cannot draw Svg; "reduced motion freezes SMIL" is false.
- **C3 (tolerable):** a Client cannot animate a Raster; Raster repaint runs on the hooks timer.

## Attack on the consensus
The honest zero-surface message rides a channel that changes Claude: a command reply is read by the model, so a crew report puts Kit, Dot and a summary into Claude's context ("unchanged" broken), while the model-blind `$.session.append` is unverified in cloud. Fix: the reply is one fixed sentence (≤20 tokens), only when the person typed /workplace; anything longer goes through `$.session.append`. And capping ceremony to fit live truth is the bill for delight: a 600 ms walk across a room skates at 400 px/s; a 1.2 s duet is an arrow.

(c) A/C layout with Image on kitty (PNG, 4–7 ms, ≤2/s, local). (d) adopt early walks for animation only, never in the strip/status/chips, cancel at 3 s. (e) 1/s and only when markup changes. (f) unassigned.

## Criterion 10
A `machines` map keyed by agentId or "main" {model, effort, parentId, type, description, steps, t0, durationMs, usage}: first `turn.step` powers on, each later step adds a request, `turn.complete` powers off and fills tokens and run time; `$.agent.list()` once per new agentId, never polled. Native Text rack rows (subagents indented): `● main · opus · high · 3 req · 0:42` → `○ main · opus · 41.2k in (38k cache) · 1.9k out · 0:58`; tokens never faked while running. Art: an IT-lab LED rack Svg (≤3 KB) blinking via CSS with negative delays, re-sent only on power on/off (≤1/s). Status line `⚡3 on`. ≈80 B per change, ≤1 KB/s.

## Steal / concessions
Steals: A's early walks (animation only), minimap, G1–G7 trace tests; B's "skipped, not queued", no frame loop; C's receipt line, notifications only when unfocused or >30 s, ceremony only shows ledger facts.
Concedes: a one-file all-rooms Episode is impossible (≤4 visited rooms ≈80 KB, or one Svg per chapter); Episode motion must be CSS; the recap moves to `$.session.append`; text-only terminals were wrong (Raster is local and liked); no autoplay after a new prompt or when the pane is hidden.
